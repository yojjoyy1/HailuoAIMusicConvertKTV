# 🎤 MP3 → MP4 KTV 歌詞影片製作工具

在瀏覽器裡把 MP3 做成有背景、有 KTV 動態歌詞的 MP4 影片，並附一個從 MP3 產生 `.lrc` 歌詞時間軸的工具。

全部在自己的電腦上執行，音樂、圖片、影片都**不會上傳**到任何伺服器，也不需要安裝任何軟體。

包含兩個網頁：

| 網頁 | 檔案 | 用途 |
| --- | --- | --- |
| MP4 製作頁 | `index.html` | MP3 ＋ 背景 ＋ KTV 歌詞 → 輸出 MP4 |
| LRC 產生器 | `lrc.html` | 從 MP3 取得歌詞並產生 `[分:秒]` 時間軸 → 輸出 `.lrc` |

---

## 🚀 開啟方式

### Mac

在資料夾裡點兩下 **`啟動.command`**，瀏覽器會自動打開 `http://localhost:8765`。

- 第一次如果被系統擋下來，請在檔案上按右鍵 →「打開」。
- 使用期間不要關掉跳出來的終端機視窗；關掉它網頁就會停止。
- LRC 產生器可以從 MP4 製作頁右上角的「📝 MP3 → LRC」進入，或直接打開 `http://localhost:8765/lrc.html`。

### 其他系統

在這個資料夾開終端機，執行：

```bash
python3 -m http.server 8765
```

然後用瀏覽器打開 `http://localhost:8765`。

> 💡 MP4 製作頁可以直接點兩下 `index.html` 使用，但 **LRC 產生器的 AI 辨識一定要用上面的方式開啟**（網址要是 `http://localhost` 開頭）。

### 建議瀏覽器

最新版 **Chrome、Edge 或 Safari**。頁面右上角會顯示目前的瀏覽器能不能直接輸出 MP4；不支援的瀏覽器會改存成 WebM。

## 🎬 MP4 製作頁（`index.html`）

### 1. 音樂

- 點擊或拖曳 MP3 檔案。
- 歌名、歌手會從檔名自動帶入（檔名格式是「歌手 - 歌名」時會自動拆開），也可以自己修改。
- 勾選「前奏時顯示歌名」，前奏期間畫面中央會顯示歌名和歌手。

### 2. 背景

預設是 **無**（純色背景，可選顏色）。

**圖片**

- 可以放一張或多張，可拖曳排序。
- 每張圖片都能各自設定：
  - **轉場**：無、淡入淡出、向左／右／上／下推移、放大進入、縮小進入、擦除、圓形展開、百葉窗、模糊轉場、旋轉進入
  - **轉場秒數**
  - **畫面動態**：靜止、緩慢放大、緩慢縮小、向左平移、向右平移
  - **顯示秒數**
- 時間分配：「平均分配到整首歌」或「每張自訂秒數」（不夠長會循環）。
- 「一次套用到全部」可以一次替所有圖片設定相同效果。
- 顯示方式：填滿畫面（會裁切）、完整顯示（留邊）、完整顯示＋模糊背景。

**影片**

- 影片原本的聲音會自動移除，只保留你的 MP3。
- 影片比歌短時可以循環播放。

**背景變暗**：讓背景暗一點，歌詞會更清楚。

### 3. 歌詞

支援 **LRC 格式**：

```text
[ti:歌名]
[ar:歌手]
[00:12.00]第一句歌詞
[00:16.50]第二句歌詞
[00:21.00]
[00:25.00]間奏後的下一句
```

- 每行前面的 `[分:秒.百分秒]` 是這句**開始唱**的時間。
- **只有時間、沒有字**的行代表「上一句唱完了」，間奏時歌詞會先消失。
- 進階：逐字 KTV（每個字變色的時間更精準）

  ```text
  [00:25.00]<00:25.00>我<00:25.40>愛<00:25.90>你<00:26.80>
  ```

沒有時間軸的純文字歌詞，可以用 **🎯 打點對時工具**：

1. 貼上歌詞（一行一句），按「開始」，音樂會從頭播放。
2. 每一句開始唱時按 <kbd>空白鍵</kbd>。
3. 一句唱完後是間奏就按 <kbd>X</kbd>；按錯按 <kbd>Z</kbd> 復原（會倒退 3 秒）。
4. 完成後按「套用」。

**KTV 效果**

- 唱到的字會從左到右逐漸變色。
- 顯示方式：KTV 雙行（左上／右下交替）或置中（目前這句＋下一句）。
- 間奏結束前，下一句會出現 ●●● 倒數。
- 可調整字體、大小、外框粗細、已唱／未唱顏色、離底部距離，並有配色快選。
- 「歌詞時間微調」可以讓整體歌詞提早或延後（正數＝延後）。

### 4. 輸出

- 解析度：1920×1080、1280×720、1080×1920（直式／短影音）、1080×1080（正方形）
- 影格率：24／30／60 fps
- 畫質：4／8／14 Mbps
- 按「🎬 開始輸出影片」，完成後會自動下載。

> ⚠️ **輸出是即時錄製**：會從頭完整播放一次歌曲，所需時間＝歌曲長度。
> 輸出期間請讓這個分頁保持在前景，**不要切換分頁或縮小視窗**，否則影片可能會卡頓。
> 若不想聽到聲音，可勾選「輸出時喇叭靜音」，不會影響影片裡的聲音。

## 📝 LRC 產生器（`lrc.html`）

### 1. 放入 MP3

放入後會自動檢查 MP3 裡有沒有**內嵌歌詞**（ID3 標籤）：

- 有同步歌詞（帶時間）→ 直接放進編輯區。
- 只有歌詞文字（沒有時間）→ 放到「貼上歌詞再對時」，再用打點補上時間。
- 歌名、歌手也會一起讀出來。

### 2. 取得歌詞

**🤖 AI 聽歌辨識**

使用 Whisper 語音辨識模型，在瀏覽器裡「聽」歌曲並自動產生每一句的時間。

| 模型 | 大小 | 說明 |
| --- | --- | --- |
| 極小 | 約 40 MB | 最快 |
| 小 | 約 80 MB | 預設 |
| 中 | 約 250 MB | 較準 |
| 大 | 約 800 MB | 最準，建議電腦有 GPU |

- 第一次使用需要下載模型（需要網路），之後會快很多。
- 可選語言：中文、英文、日文、韓文、自動偵測。
- 辨識後的自動整理：中文轉繁體、長句自動切開、移除標點、過濾 AI 常見的亂入字（如「字幕由…提供」）、句子間空檔太長自動加上句尾標記。

> 💡 有伴奏的歌曲，AI 可能聽錯字或漏句，辨識完請播放檢查並修正。
> 手上有正確歌詞的話，用下面的「貼上歌詞再對時」準確度最高。

**📋 貼上歌詞再對時**

- 貼上歌詞（一行一句）→「放進編輯區」→ 用右邊的「🎯 依序打點」補上時間。
- 也可以按「放進去並平均分配時間」先粗略分配，再慢慢微調。
- 貼上的如果已經是 LRC 格式，會保留原本的時間。

### 3. 檢查與修正時間軸

每一句都可以：

- 直接修改歌詞文字或時間（格式 `分:秒.百分秒`，例如 `01:23.45`）
- `−`／`＋`：提早／延後 0.1 秒
- `▶`：從這句開始播放
- `⏱`：把時間設成目前播放位置
- `＋`：在下面插入一句；`✕`：刪除

其他功能：新增一句、新增句尾標記、依時間排序、整體平移、清空。
播放時，正在唱的那句會亮起來；黃框代表這句還沒有時間。

**🎯 依序打點**：音樂從頭播放，每一句開始唱時按 <kbd>空白鍵</kbd>，<kbd>Z</kbd> 復原，<kbd>Esc</kbd> 結束。

### 4. 輸出 .lrc

- **💾 下載 .lrc**
- **📋 複製**
- **➡ 送到 MP4 製作頁**：歌詞和歌名、歌手會直接填進 MP4 製作頁的「3. 歌詞」。
  （瀏覽器無法自動帶過去音樂檔，請在 MP4 製作頁再放一次同一首 MP3。）

| 按鍵 | 作用 |
| --- | --- |
| <kbd>空白鍵</kbd> | 播放／暫停（打點時＝打下一句） |

## ❓ 常見問題

**輸出的影片是 WebM 不是 MP4？**
目前的瀏覽器不支援直接錄製 MP4，請改用最新版 Chrome、Edge 或 Safari。

**輸出的影片卡卡的？**
輸出期間切換了分頁或縮小了視窗。請重新輸出，並讓頁面保持在前景。

**AI 辨識按了沒反應或出現錯誤？**
- 確認是用 `啟動.command` 開啟的（網址是 `http://localhost` 開頭）。
- 第一次需要網路下載模型，請確認網路連線。
- 電腦比較舊的話，改用「極小」或「小」模型。

**歌詞時間整體快了或慢了？**
LRC 產生器用「整體平移」，或在 MP4 製作頁調整「歌詞時間微調」。

**歌詞在間奏時沒有消失？**
在那句後面加一行「只有時間沒有字」的句尾標記，例如 `[01:05.20]`。
